โจทย์ที่แอปนี้แก้ให้

ผู้เรียนเศษส่วนมักเข้าใจคำตอบแต่ไม่เห็นกระบวนการ — แอปนี้แก้ปัญหานั้นด้วยการรับอินพุตเป็นนิพจน์เศษส่วน จำนวนเต็ม หรือจำนวนผสม สร้างโจทย์ใหม่ตามพารามิเตอร์ที่ผู้ใช้กำหนด (ขอบเขตตัวเศษ/ตัวส่วน, ชนิดการดำเนินการ, จำนวนโจทย์) แล้วคำนวณผลลัพธ์แบบแม่นยำพร้อมแสดงขั้นตอนพีชคณิตทีละขั้น — แต่ละขั้นมีทั้งสัญกรณ์คณิตศาสตร์และภาพประกอบ (แถบหรือวงกลมแบ่งส่วน) กำกับ

สถาปัตยกรรมที่แนะนำ: เว็บหรือแอปข้ามแพลตฟอร์ม ใช้ไลบรารีคำนวณเชิงสัญลักษณ์ (math.js หรือ SymPy) ร่วมกับตัวเรนเดอร์สมการ (KaTeX เหนือกว่า MathJax ด้านความเร็วราว 20–30 เท่า) และกราฟิก SVG/Canvas สำหรับภาพประกอบ หากไม่ระบุขอบเขตค่า ระบบถือว่าไม่มีข้อจำกัด แต่แนะนำให้ผู้ใช้กำหนดเองเพื่อประสิทธิภาพที่ดี

สิ่งที่ระบบต้องทำได้

ครอบคลุมตั้งแต่รับอินพุต สร้างโจทย์ คำนวณ ไปจนถึงแสดงผลลัพธ์แบบเข้าถึงได้

  • อินพุตเศษส่วน/จำนวนผสมรูปแบบ "ตัวเศษ/ตัวส่วน" เช่น 3/4 หรือ "a b/c" เช่น 2 1/3
  • สร้างโจทย์อัตโนมัติกำหนดชนิดการดำเนินการ ขอบเขตค่า และจำนวนโจทย์ที่ต้องการ
  • คำนวณแบบ exactเศษส่วนล้วน ไม่แปลงเป็นทศนิยม ลดรูปด้วย gcd เสมอ
  • คำอธิบายทีละขั้นเช่น หา ครน. บวกตัวเศษ ลดรูปผลลัพธ์ — อ้างอิงแนวทางของ mathsteps
  • ภาพประกอบทุกขั้นตอนแถบหรือวงกลมแบ่งส่วนที่สอดคล้องกับขั้นตอนนั้นโดยเฉพาะ
  • แสดงผลลัพธ์พร้อม LaTeXเรนเดอร์สวยงามด้วย KaTeX/MathJax พร้อมปุ่มเลื่อนขั้นตอน
  • ไม่จำกัดค่าโดยปริยายหากผู้ใช้ไม่ระบุขอบเขต ถือว่าไม่มีข้อจำกัด แต่แนะนำให้กำหนดเพื่อประสิทธิภาพ
  • ประสิทธิภาพใช้อัลกอริทึมยูคลิดหา gcd ซึ่งมีประสิทธิภาพสูงสำหรับตัวเลขขนาดใหญ่

อัลกอริทึมทางคณิตศาสตร์

การคำนวณเศษส่วนแบบแม่นยำ

ทุกการดำเนินการอิงตัวหารร่วมมากที่สุด (gcd) และตัวคูณร่วมน้อยที่สุด (lcm) ที่หาได้ด้วยอัลกอริทึมยูคลิด

การบวก / การลบ — หา ครน. ก่อนเสมอ + / −

สูตร: lcm(a,b) = |a·b| / gcd(a,b) จากนั้นแปลงเศษทั้งสองให้อยู่ส่วนเดียวกันแล้วบวก/ลบตัวเศษ ก่อนลดรูปด้วย gcd ของผลลัพธ์

12 + 34 = 24 + 34 = 54
gcd(2,4)=2 → lcm(2,4)=4 · ผลลัพธ์ 5/4 ลดรูปแล้ว (gcd(5,4)=1)

การคูณ ×

คูณตัวเศษกับตัวเศษ ตัวส่วนกับตัวส่วน แล้วลดรูปด้วย gcd

23 × 35 = 615 = 25

การหาร ÷

คูณด้วยส่วนกลับ (reciprocal) ของตัวหาร แล้วทำตามขั้นตอนการคูณ

23 ÷ 45 = 23 × 54 = 56

การลดรูป simplify

หารตัวเศษและตัวส่วนด้วย gcd ของทั้งคู่

4256 ÷ gcd=14 = 34

เลขผสม ↔ เศษเกิน convert

คูณส่วนด้วยจำนวนเต็มแล้วบวกตัวเศษ / หรือหารแบบยูคลิดเพื่อย้อนกลับ

2 34 = 114

ตัวอย่างภาพประกอบที่ระบบจะสร้าง

แต่ละขั้นตอนจับคู่กับภาพแบบแถบหรือวงกลมแบ่งส่วน เพื่อให้เห็นสัดส่วนจริง ไม่ใช่แค่ตัวเลข

โมเดลข้อมูลและ API

REST API แบบ JSON

ออกแบบให้ frontend เรียกสร้างโจทย์และขอขั้นตอนการแก้แยกกันได้ เพื่อรองรับการแชร์โจทย์ในอนาคต

Request — POST /api/solve
{
  "operation": "add",
  "operands": ["2 1/3", "4/5"],
  "maxDenominator": 20,
  "problemCount": 5
}
Response — ขั้นตอนละเอียด
{
  "status": "success",
  "problems": [{
    "expression": "2 1/3 + 4/5",
    "result": "3 2/15",
    "steps": [
      { "description": "แปลงเลขผสมเป็นเศษเกิน",
        "before": "2 1/3 + 4/5",
        "after": "7/3 + 4/5" },
      { "description": "หา ครน. ของ 3 และ 5",
        "latex": "lcm(3,5)=15" },
      { "description": "บวกตัวเศษแล้วลดรูป",
        "after": "47/15 = 3 2/15" }
    ]
  }]
}
  • POST/api/generateสร้างชุดโจทย์จาก operation, ขอบเขตค่า และจำนวนที่ต้องการ
  • POST/api/solveรับนิพจน์หรือรหัสโจทย์ คืนผลลัพธ์และขั้นตอนทั้งหมด
  • GET/api/problems/{id}ดึงโจทย์เดิมเพื่อแชร์หรือย้อนกลับมาทำต่อ
  • GET/api/steps/{id}ดึงเฉพาะขั้นตอนการแก้ของโจทย์ที่ระบุ

ชื่อคีย์ JSON ใช้ภาษาอังกฤษเพื่อความสะดวกในการพัฒนา/debug ส่วนข้อความอธิบาย (description) เป็นภาษาไทยเสมอ

ออกแบบเพื่อผู้เรียนไทยทุกคน

การเข้าถึง (Accessibility)

  • คอนทราสต์สูงหลีกเลี่ยงสีอ่อนบนพื้นอ่อน ทั้งข้อความและกราฟิก
  • Alt text ภาษาไทยทุกภาพประกอบมีคำบรรยาย เช่น "แถบแบ่งส่วนเศษ 3/5"
  • คีย์บอร์ดนำทางได้ทดสอบด้วย Lighthouse หรือ axe ตามแนวทาง WCAG
  • โครงสร้างหัวข้อชัดเจนheading/list เรียงลำดับ ไม่ซ้อนเนื้อหาแบบสับสน

การรองรับภาษาไทย (Localization)

  • ศัพท์คณิตศาสตร์มาตรฐาน"บวก" "คูณ" "เศษส่วน" ตรงตามหลักสูตรไทย
  • ฟอนต์รองรับไทยเต็มรูปแบบNoto Sans Thai, Sarabun, Leelawadee UI
  • โครงสร้าง i18ni18next / react-intl เผื่อขยายภาษาอื่นในอนาคต
  • Responsive ทุกอุปกรณ์ปรับขนาดได้ทั้งเดสก์ท็อปและมือถือ
